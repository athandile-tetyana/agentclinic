# Roadmap

## Phase 1 — Project bootstrap

- Initialize the Next.js + TypeScript app
- Add the basic app shell and page structure
- Confirm the project runs in a modern browser

## Phase 2 — Data foundation

- Create the SQLite database schema
- Add tables for agents, ailments, therapies, and appointments
- Confirm basic read/write operations work locally

## Phase 3 — Agent directory and dashboard

- Build the main dashboard view for agent records
- Add agent listing and status summaries
- Show a simple operational overview for staff

## Phase 4 — Ailments and therapy workflows

- Add support for recording agent ailments and symptoms
- Define relevant therapies and recommended actions
- Connect therapies to each agent record

## Phase 5 — Appointment booking

- Add appointment creation and scheduling flow
- Show upcoming meetings and appointment status
- Keep the booking flow simple and easy to understand

## Phase 6 — UX polish and demo readiness

- Improve page styling, layout, and responsiveness
- Validate the key user journeys end-to-end
- Prepare the product for student learning and conference demos
