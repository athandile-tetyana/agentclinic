# Tech Stack

## Recommended architecture

We will build AgentClinic as a full-stack TypeScript application using Next.js and SQLite.

## Why Next.js

- Popular, modern framework for TypeScript-based web apps
- Combines frontend and server-side routes in one familiar stack
- Good fit for dashboards, demo pages, and simple data-driven product experiences
- Easy to explain and present in a conference or teaching environment

## Core stack

- TypeScript
- Next.js
- React
- SQLite
- Prisma or a lightweight typed data layer for local persistence
- Tailwind CSS or a similar modern styling approach for a polished browser experience

## Data layer

We will use SQLite for persistence because it is lightweight, portable, and easy to run locally for a prototype and demo. It supports early product needs without adding operational overhead.

## Frontend and UX

- Modern browser-friendly interface with a polished layout
- Clear dashboard for staff and operational visibility
- Responsive design suitable for demos and teaching scenarios

## Operational principles

- Prefer a familiar, reliable framework over unnecessary complexity
- Keep the stack easy to onboard and easy to demo
- Optimize for iteration speed while maintaining a stable product foundation
